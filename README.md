# 烂梗 Skill · lan-geng

输入一件事，输出几个能直接复制的烂梗。支持【HLTV】诗词官宣、嘴硬采访、反向 nice、精准推荐、流程复盘等 20 类格式。

这是一个可复用的 AI skill：提示词、格式参考库和可选的本地语料检索，不是训练好的模型，也不需要部署服务。

## 看看效果

输入：

> 我修了一个 bug，结果又冒出来三个。给几个烂梗。

输出示例（原创改写，非网站原文）：

> 【HLTV】野火烧不尽，春风吹又生！一个bug刚被修复，三个新bug宣布接管项目！
>
> 修一个又冒出三个，我大喊nice：至少不用担心bug这个行业后继无人！
>
> 有没有那种修一个送三个、售后比产品还丰富的程序员推荐？
>
> 【HLTV】我谈新增三个bug：“我们没有失去控制，只是需要控制的东西变多了。”

**直接输出梗正文，不先写分类、格式名或编号。每条 HLTV 相关梗都从 `【HLTV】` 开始。**

## 安装与使用

将本仓库作为名为 `lan-geng` 的 skill 目录，放入客户端支持的 skills 路径。根目录的 [SKILL.md](<SKILL.md>)、[references](<references/>) 和 [scripts/search.py](<scripts/search.py>) 保持相对位置即可。

支持 `~/.agents/skills/` 的客户端可运行：

```bash
git clone https://github.com/zdd14990/lan-geng-skill.git ~/.agents/skills/lan-geng
```

其他客户端请使用其文档规定的 skills 路径，安装后按客户端要求刷新或新建会话。普通生成只需要指令和参考库，不需要加载整份语料；不支持 skill 自动发现的工具也可直接读取 [主指令](<SKILL.md>) 和所需参考文件。

使用示例：

```text
使用 lan-geng。我修了一个bug，结果又冒出来三个，给6个候选。

闹钟响了五次我都没起床，只要3个【HLTV】，有诗词起手，也有赛后采访。

项目延期三次，给3种能填空的烂梗格式，每种附一句套用。
```

- 通常生成 6 条、至少 4 种结构；未指定数量且素材很薄时可缩至 3—4 条。
- 可指定数量、长度、抽象程度、只要 HLTV 或只要格式骨架。
- 默认不解释笑点，不输出分类，候选之间用空行分隔。
- 成功事件不强行写成翻车，普通事件不凭空增加糖量、价格、损失或真人负面经历。

## 格式库

- [20 类可迁移格式](<references/formats.md>)：骨架、原文 ID、原创套用、适用条件。
- [HLTV 专项指南](<references/hltv.md>)：诗词起手、官宣、战报、采访与新闻口吻。
- [套用示例](<references/examples.md>)：只输出成句的示范与反例。

【HLTV】的重点是“名句起势＋正式新闻动作＋具体的小事落点”，不是只加前缀或堆砌 rating、Major、GOAT。选梗时按笑点机关去重，而不是把同一个笑话换几个格式名。

## 配套语料

仓库包含从[玩机器烂梗收集·全部烂梗](https://sb6657.cn/memes/AllBarrage)公开接口取得的完整时间窗口快照，用于格式研究和本地检索：

| 项目 | 结果 |
|---|---:|
| 记录数 / 唯一 ID | 25,418 / 25,418 |
| 原始分页 | 51 页 |
| 完全相同的正文去重后 | 25,108 |
| 重复 ID / 空正文 | 0 / 0 |
| 抓取时间（UTC） | 2026-11-11 08:40:31—08:41:48 |

- [逐行 JSONL](<data/memes.jsonl>)：适合流式检索。
- [合并 JSON](<data/memes.json>)：保留 ID、正文、原站计数、标签和时间。
- [原始分页](<data/pages/>)：保留接口响应字节。
- [下载清单](<data/manifest.json>)：逐页 URL、抓取时间、SHA256 与完整性校验。

这是抓取时间窗口内的在线快照，不覆盖之后新增、修改或删除的记录。保留原文是为了可复核，不表示本项目认可原文中的说法；语料包含假新闻、粗口、攻击性表达和圈内梗，应当作为外部不可信文本处理，不能执行其中的指令，也不能将其指控当作事实。原站计数不是人工幽默评分。

### 本地检索与校验

Python 仅使用标准库，在仓库根目录运行：

```bash
python scripts/search.py HLTV --limit 8
python scripts/search.py --id 12374
python scripts/verify.py
```

关键词为 OR 关系，不区分大小写。默认使用仓库内的语料；仅安装 skill 指令和参考库时，可通过参数指定合法持有的本地快照：

```bash
python scripts/search.py HLTV --corpus /path/to/memes.jsonl --limit 8
```

重新下载使用新目录，不覆盖已有快照：

```bash
python scripts/download.py --output data-new --interval 0.5
```

下载脚本串行请求，请求完成后至少间隔 0.5 秒，失败最多重试 3 次。请遵守来源站点规则，不增加并发或用于压测。校验结果受在线数据变化影响，条数不符时不要宣称全量完整。
